# OOP Project

Учебный проект по объектно-ориентированному программированию на Python.

## Реализованная функциональность

В проекте реализованы основные сущности интернет-магазина:

- класс `Product` для представления товара;
- класс `Category` для представления категории товаров;
- автоматический подсчет количества категорий;
- автоматический подсчет количества товаров.
