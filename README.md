# OOP Project

Учебный проект по объектно-ориентированному программированию на Python.

## Реализованная функциональность

В проекте реализованы основные сущности интернет-магазина:

- класс `Product` для представления товара;
- класс `Category` для представления категории товаров;
- класс `Smartphone`, наследующийся от `Product`;
- класс `LawnGrass`, наследующийся от `Product`;
- автоматический подсчет количества категорий;
- автоматический подсчет количества товаров;
- приватное хранение списка товаров категории;
- добавление товаров через метод `add_product`;
- защита от добавления объектов, не являющихся товарами;
- получение информации о товарах через `@property`;
- создание товара из словаря через `Product.new_product`;
- приватное хранение цены товара;
- получение и изменение цены через геттер и сеттер;
- защита от установки нулевой или отрицательной цены;
- строковое представление товара через `__str__`;
- строковое представление категории через `__str__`;
- сложение стоимости запасов товаров через `__add__`;
- запрет сложения товаров разных классов.

## Класс Product

Класс `Product` содержит:

- название;
- описание;
- цену;
- количество в наличии.

Цена хранится в приватном атрибуте и доступна через свойство `price`.

Метод `new_product` позволяет создавать новый товар из словаря.

Метод `__str__` возвращает информацию о товаре в строковом формате.

Метод `__add__` позволяет получить общую стоимость запасов двух товаров одного класса.

## Класс Smartphone

Класс `Smartphone` наследуется от `Product`.

Дополнительные атрибуты:

- производительность;
- модель;
- объем встроенной памяти;
- цвет.

## Класс LawnGrass

Класс `LawnGrass` наследуется от `Product`.

Дополнительные атрибуты:

- страна-производитель;
- срок прорастания;
- цвет.

## Класс Category

Класс `Category` содержит:

- название категории;
- описание;
- приватный список товаров.

Метод `add_product` позволяет добавлять только объекты `Product` и его наследников.

Свойство `products` возвращает информацию обо всех товарах категории.

Метод `__str__` возвращает название категории и общее количество товаров на складе.

Также класс хранит общие счетчики:

- `category_count` — количество созданных категорий;
- `product_count` — количество товаров во всех созданных категориях.
